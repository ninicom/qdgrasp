## Lý do chỉnh sửa

Kế hoạch legacy đề xuất phụ thuộc trực tiếp package Ultralytics và giữ nhiều giả
định chưa phù hợp. Người dùng yêu cầu lấy kiến trúc và các khối từ source clone
chuẩn của Ultralytics, lấy code chuẩn DexGraspNet2 thay vì suy diễn, thiết kế lại
model theo YAML với backbone/neck/head, và bảo đảm core hỗ trợ CPU lẫn CUDA.

Kế hoạch mới cũng sửa phát biểu tuyệt đối rằng MinkowskiEngine chỉ chạy CUDA,
tách core thuần PyTorch khỏi simulator GPU tùy chọn, và đặt license thương mại
thành gate trước hành vi sao chép/sửa/phân phối code có liên quan.

## Mức độ cần thiết

- Mức đã chọn: `N3` — khẩn cấp/ảnh hưởng quyết định lớn và phát hành.
- Lập luận: thay đổi chạm kiến trúc lõi, provenance source, nghĩa hỗ trợ CPU/GPU
  và điều kiện pháp lý của việc fork/phân phối. Dùng tiếp kế hoạch cũ có thể làm
  triển khai đi sai hướng và tạo nợ tái cấu trúc lớn.
- Thời hạn: phải áp dụng trước khi bắt đầu M0/M1 hoặc sao chép code upstream.
- Biện pháp nếu trì hoãn: không bắt đầu port, đóng gói hay phát hành.
